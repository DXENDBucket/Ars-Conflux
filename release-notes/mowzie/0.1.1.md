# Mowzie & Nouveau 0.1.1

Requires Ars Conflux 0.1.32.

Add Dampen and Duration Down wherever the corresponding positive modifier is supported. Native damage/channel/poison/geomancy logic now consumes signed values, with final-result lower bounds. Existing positive baselines, alliance checks and resource-exhaustion cleanup remain intact. Higher-tier positive amplification equivalents use weighted units for the existing surcharge.
