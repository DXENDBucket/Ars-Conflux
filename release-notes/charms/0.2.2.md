# Goety Charms 0.2.2

Initial CurseForge release for Minecraft 1.21.1 / NeoForge and 1.20.1 / Forge.

- Seal supported Goety summoning, conversion, teleportation and locating rituals into single-use charms using the native Dark Altar.
- Preserve source research, materials, environment, sacrifice, ritual duration and soul fees during preparation. Successful survival releases consume one charm; failed releases retain it and creative use does not consume it.
- Preserve native summoned creatures, ownership, variants, equipment and applicable summoning limits. Conversion tooltips identify their valid creature targets.
- Teleportation retains the actual waystone destination and native same-dimension behavior. Locating searches from the use location and delivers the original exploration map before consuming the charm.
- Add native JEI sealing recipes, bilingual text, distinct charm seals and the bucket-series project icon.
- Craft four Blank Charms with paper in the center and quartz on the four cardinal sides.
- Expose the optional `CharmAccess` API for integrations. Goety & Nouveau 0.1.13+ can use it for the Activate Charm effect; Ars mods are not required by Goety Charms itself.

Requires Goety and its dependencies. MIT, EndXiom.
