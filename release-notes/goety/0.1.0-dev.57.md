# Goety & Nouveau 0.1.0-dev.57

- Fix missing native Goety attribute bonuses in older projectile, effect and summon adapters. Native attributes, focus enchantments and Ars augments now apply at their respective stages without double counting.
- Restore Goety's enchanted-focus cost multiplier when the native `enchantMultiCost` option is enabled. An equipped enchanted focus doubles the native focus cost before flat addon augment fees and the existing Soul discounts. Ars Amplify alone does not activate this multiplier.
- Preserve the existing Soul Energy and Ars Mana resource modes, failed-cast refunds and creative-mode bypass.
- Match Flying potency to the installed Goety version: current versions add focus potency to native attributes; supported older versions retain their original replacement rule.

Targeted server-side checks passed with Goety 3.2.1 on Minecraft 1.21.1 / NeoForge and Goety 2.5.59.2 on Minecraft 1.20.1 / Forge. Older supported Goety versions received API and behavior inspection, without a new runtime test.

Requires Ars Conflux 0.1.24 or newer 0.1.x.
