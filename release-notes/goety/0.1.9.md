# Goety & Nouveau 0.1.9

**Requires Ars Conflux 0.1.47 or newer within 0.1.x.**

Minecraft **1.21.1 NeoForge** and **1.20.1 Forge**.

- Fix head-versus-body direction mismatches in Ars-triggered allied breaths, block traces, horizontal offsets, corruption beams and water whips. Native particle types, spread, speed and damage lifecycle are retained.
- Use the real recipient's head view for Launch movement, and the caster's head view for self-triggered Bolting and directional fallbacks. Existing destination/target semantics are retained.
- Add an optional non-player soul-account API for content integrations, plus quiet summon/buff usefulness hints and valid NPC combat-target inheritance for native servants. Unsupported mobs do not gain a free soul-energy pool.
- Validate allied Chill Hide against the selected recipient. Player resource modes, native summon limits and Summon Down remain authoritative.

Validation: both platform distributions compile and package successfully; metadata and declared Forge refmaps were checked. This batch has not been checked in a running client or server.
