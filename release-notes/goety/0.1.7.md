# Goety & Nouveau 0.1.7

**Requires Ars Conflux 0.1.45 or newer.** Available for Minecraft **1.21.1 NeoForge** and **1.20.1 Forge**.

- Expose provider-owned resource and cooldown information for optional non-player casting integrations.
- Apply native-derived focus cooldowns to supported non-player casts, preserving native focus identity and existing rapid-fire exceptions.
- Add optional ability hints for checked attack, defense, healing, control, summoning and channeling glyphs. Player-only native-focus fallbacks remain marked accordingly.
- Keep default soul-energy payment authoritative. Mobs without a usable soul account do not cast for free; explicitly choosing the existing Ars resource mode allows integrations to use their native Ars mana pool.

This update does not install AI, equip mobs or alter normal spawning. Player-native timing, configured resource selection and native summon limits are retained. Targeted coexistence checks cover a real non-player buff, payment and cooldown; client visuals were not manually rechecked.
