# Goety & Nouveau 0.1.10

- Native Goety equipment checks can now find real Curios equipped by non-player entities, using the same item/predicate rules as player equipment checks.
- NPC content supplies its own slots and equipment. No virtual set bonuses or automatic equipment are added by this addon; ordinary player lookup remains unchanged.
- Requires Ars Conflux 0.1.47 or newer in the 0.1.x series. Includes the allied breath, beam and movement direction fixes from 0.1.9.
- Both loaders are compiled and packaged; this batch is checked statically without launching an in-game test.
