# Goety & Nouveau 0.1.5

**Requires Ars Conflux 0.1.40 or newer.**

- Support Conflux's shared cooldown and cast-time reduction attributes after native Goety equipment modifiers.
- Apply preparation reduction to automatically discovered self-casting focuses and Prisma Beam's target-dependent charge while preserving completed native charge progress.
- Support custom cooldowns written directly by native/addon focuses inside managed self-casting scopes.
- Prevent cooldowns passing through both the bridge and a native callback from receiving the same reduction twice.

Both attributes default to **0**. Ordinary Goety wand casts outside this integration retain their native rules. Soul-energy costs, channel output durations and pulse intervals retain their existing behavior.

Available for Minecraft **1.21.1 NeoForge** and **1.20.1 Forge**.
