# Goety & Nouveau 0.1.14

For Minecraft **1.21.1 NeoForge** and **1.20.1 Forge**.

- Add **Hell Cloud**, **Void Lightning Trap** and **Hysteria** effect glyphs, plus **Ill Bomb** and **Death Arrow** projectile replacements.
- Retain native cloud rain, delayed lightning telegraphs, particles, bouncing, shield reflection and the bomb's firework branch. Successful creation of delayed firework payloads can continue the remaining Ars effects.
- Death Arrow keeps its native equipment and Nether requirements. Its additional percentage-health loss is capped at 20 health per qualified hit by default; the cap can be configured or disabled.
- Hysteria works on yourself or an ally, granting powerful melee and speed bonuses at the cost of continuous, potentially lethal health loss. Native platform-specific behavior is retained.
- Include actual Scribe recipes, trigger resource billing, configurable preparation/cooldowns, ally protection and AI hints for these abilities. Default resources remain Goety soul energy, with the existing Ars Mana option available.

Five focused server tests passed on each loader, covering native payloads, resource payment, delayed effects, reflection and continuation rules. Release metadata, resources and Forge mappings were checked. Client visuals have not been manually verified.
