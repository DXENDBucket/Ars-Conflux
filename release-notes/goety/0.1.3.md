# Goety & Nouveau 0.1.3

Includes the registration fixes from 0.1.2 and 0.1.3 for both Minecraft 1.21.1 NeoForge and 1.20.1 Forge.

- Fix duplicate generated-glyph item registration when a Goety addon registers focuses before Ars Nouveau. This addresses the reported Goety Cataclysm Sandstorm Focus startup error.
- Keep both early and late focus registration working, without changing existing generated glyph IDs, recipes, learned state or configuration paths.
- Only discover focuses from the actual Minecraft item registry. Custom registries containing references to existing focuses no longer create extra glyphs or recipes referencing nonexistent items.
- Keep strict collision checks rather than suppressing genuine item-ID conflicts.

Verified with a targeted registration regression on both loaders, covering early/late focuses, repeated observations, a real custom registry, source model references and loaded Scribe recipes.

No new Core requirement or resource-source gameplay change.
