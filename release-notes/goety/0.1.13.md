# Goety & Nouveau 0.1.13

For Minecraft **1.21.1 NeoForge** and **1.20.1 Forge**.

- Add **Activate Charm / 启符**, a tier-one effect glyph available when **Goety Charms 0.2.2 or newer** is installed.
- Trigger a sealed summoning charm at the Ars hit location, or a conversion charm on the selected living entity. The original player supplies the charm and retains native ownership.
- Select charms from the offhand first, then the hotbar from left to right, then the main inventory row by row. An unsuitable target retains the selected charm; it does not silently try another one.
- Support summoning and conversion charms. Teleportation charms, location charms and unsealed samples are skipped. Native ritual restrictions and summon limits remain in effect.
- The glyph adds no Mana/soul cost, preparation or cooldown; sealing has already paid the ritual costs. Each successful trigger consumes one charm in survival. Creative mode retains it.
- Learn it at an Ars Scribe's Table using **Blank Charm + Source Gem**, costing 27 experience points. Without Goety Charms, neither this glyph nor its recipe is added.

Both platform releases and regression test sources compile successfully. Packaging, optional dependency boundaries and Forge production refmap checks passed. This update has not been validated by launching a client, server or GameTest.
