# Ars Conflux 0.1.53

- Fixed a **Forge 1.20.1 startup crash with Ars Nouveau 4.12.7** caused by the projectile-category name hook targeting `AbstractAugment.getTypeName()`, an Ars 5-only method.
- Isolated that hook to NeoForge 1.21.1. Forge retains its projectile-replacement category, glyph frames and spell-wheel previews.
- Added a Forge distribution check to prevent the incompatible hook from being packaged again.
- No changes to spell costs, damage, glyph IDs or saved spells.

Both platform packages were built and inspected, including Forge production remapping. Additional static checks covered the available mod-targeted Mixin entrypoints; no full game launch was performed for this hotfix.
