# Ars Conflux 0.1.25

- Add configurable native Ars glyph frames for registered addon glyphs.
- Support category colors, uniform or custom colors, center scaling, and optional original icon sources.
- Preserve native 3D item rendering and Ars invalid-spell fading.
- Add the neutral `GlyphVisuals` and `GlyphIcon` APIs for addon icon providers.
- Load frame art from Ars resources at runtime, including resource pack overrides.

Available for Minecraft 1.21.1 / NeoForge and Minecraft 1.20.1 / Forge.
