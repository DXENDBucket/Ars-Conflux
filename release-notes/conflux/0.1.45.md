# Ars Conflux 0.1.45

Available for Minecraft **1.21.1 NeoForge** and **1.20.1 Forge**.

Changes since 0.1.42:

- Convert the native lesser and greater mana-discount rings to configurable **10% / 20%** reductions by default. Native Ars costs and supported addon trigger payments share the same percentage calculation. Disable the option to restore native flat discounts; soul energy is unaffected.
- Add optional per-glyph ability hints with reloadable datapack overrides and a public declaration API. Hints describe abilities and recipients without changing native schools or casting permissions.
- Provide a lazy, native Ars mana lifecycle for non-player casters, including capacity, regeneration, save/load, exact spending and transfers. Integrations can supply their own capacity policies; no second mana currency is introduced.
- Add combined first-activation resource budgets, provider-owned cooldown queries and optional usefulness predicates for AI and content integrations. Unknown prices are not treated as free casts.
- Preserve the real mob's damage attribution when native Ars uses an interaction proxy internally.

**Core does not install AI, equip creatures, choose their enemies or change natural spawning.** Reusable casting AI is provided separately by Ars Instinct. Ordinary player behavior remains native except for explicitly configured features such as the discount-ring conversion.

Targeted standalone and integration checks cover non-player mana, real Ars attack/heal casting, provider timing, native upfront and trigger billing, and resource preservation. Client visuals were not manually rechecked in this update.
