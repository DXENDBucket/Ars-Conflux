# Ars Conflux 0.1.36

Includes the changes from 0.1.33 through 0.1.36.

## Optional Ars Zero integration — Minecraft 1.21.1 NeoForge

- Add support for Ars Zero **2.0.2** staff and circlet casts, including shared preparation and cooldown handling.
- Correct repeated Beam and Geometrize billing when the remaining spell contains Conflux-managed effects.
- Fix the staff/circlet glyph grid: each category starts on a new row, category icons count toward pagination, and addon ordering is retained.
- Let reflective Arcane Shields interact with Conflux-managed projectiles, including native projectiles from spell providers. Reflection preserves the original resource account and updates damage credit; unsupported fixed trajectories are absorbed.
- Connect Push, Anchor and Remove Gravity to managed projectiles.
- Preserve Beam/Voxel impact directions through delayed continuations, and recognize Zero's higher-tier augments.
- Include compatibility fixes for temporal targeting, using the preceding execution's result.

Ars Zero remains optional. These Zero adapters target 2.0.2; other versions are not automatically opted in.

## Shared APIs — both loaders

- Add provider-neutral projectile reflection, motion control and scoped impact-direction support.
- Retain the Forge 1.20.1 build for API parity. Ars Zero integration itself is NeoForge-only.

No additional mandatory spell-provider dependency is introduced.
