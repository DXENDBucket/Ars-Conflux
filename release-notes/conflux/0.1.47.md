# Ars Conflux 0.1.47

Minecraft **1.21.1 NeoForge** and **1.20.1 Forge**.

- Add a shared live executor-view API. Living entities use their head/eye direction even when their body faces elsewhere.
- Use that view for entity execution anchors and held managed-projectile orientation. Explicit position/direction anchors and valid incoming projectile directions retain their existing priority.
- Include the configurable native Ars mana-attribute ceilings introduced in 0.1.46: default maximum mana 1,000,000 and regeneration 100,000. These are ceilings, not bonuses; larger existing limits are retained.

Validation: both platform distributions compile and package successfully; metadata and declared Forge refmaps were checked. This batch has not been checked in a running client or server.
