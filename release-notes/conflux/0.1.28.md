# Ars Conflux 0.1.28

## Forge 1.20.1: spell book pagination fixes

- Fix missing or overlapping glyphs in large addon collections, including setups with Not Enough Glyphs.
- Calculate pages from the actual glyph grid and category headings instead of splitting the list into fixed groups of 58.
- Display each glyph ID only once when known glyphs overlap with the default starting glyphs.
- Keep page counts and navigation arrows correct after filtering or searching.
- Apply the fixes to both the regular spell book and the Infinity Spell Book, preserving existing sorting and spell validation.

The NeoForge 1.21.1 release keeps its existing pagination implementation; its version is synchronized with Forge.

Available for Minecraft 1.21.1 / NeoForge and Minecraft 1.20.1 / Forge.
