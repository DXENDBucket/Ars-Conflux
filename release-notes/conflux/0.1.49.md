# Ars Conflux 0.1.49

For Minecraft **1.21.1 NeoForge** and **1.20.1 Forge**.

- Add optional **Propagate Nearby Allies** and **Propagate Carian Phalanx** subforms when Not Enough Glyphs is installed. They hand the remaining spell to the original cast method while retaining its caster, resource account and native formation rules.
- Both are tier-three glyphs, with a base cost of 100 Mana. Ars Scribe recipes use the corresponding form glyph, the relevant essence and a Source Gem.
- Existing source-form switches still apply. Nearby Allies and Carian Phalanx remain opt-in; missing or disabled integrations leave no unusable glyph recipes. Forge only registers forms that exist in that version of the original addon.
- Fix the canonical English and Simplified Chinese name keys for both new subforms.
- Add packaging checks for the actual namespaced glyph-name keys used by Ars.

Targeted server tests covered the optional form adapters during development. Both platform release packages, language keys and Forge refmaps were checked. Client visuals have not been manually verified for this update.
