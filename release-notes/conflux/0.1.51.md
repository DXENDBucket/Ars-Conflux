# Ars Conflux 0.1.51

- NeoForge: include the optional Hex Casting client service-loader fix for the reviewed pre53, pre64 and pre67 builds. The fix uses Hex's own class loader and does not require Hex-Ars Linker.
- When upgrading from the old standalone Hex client fix, remove its JAR. Conflux avoids applying a second redirect while that patch is installed, but cannot override its exact-version dependency.
- Unknown Hex versions and changed upstream service-loader code are left untouched. Hex and Linker remain optional; Forge does not install this client fix.
- Includes the 0.1.50 glyph-browser correction: NEG subforms remain together even without an addon presentation provider.

NeoForge was built against Ars Nouveau 5.13.4. The Hex/Linker test dependencies are now pinned to pre67. Three focused class-loader/bytecode tests and both distribution builds passed; this release was not validated by launching a full client modpack.
