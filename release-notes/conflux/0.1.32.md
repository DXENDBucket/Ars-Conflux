# Ars Conflux 0.1.32

- Add optional AOE / Pierce / Sensitive support to AAP Annihilate, and duration augments to Divine Smite's remaining Shocked status.
- Repair NEG Flatten's per-block interaction target and expose its existing AOE / Pierce paths.
- Count AAP high-tier Extend Time equivalents in Controle Precise Delay, preserving the native delay bound.
- Add the opt-in AugmentSupport.withReductions API for providers that handle signed stats.

Upstream augment extensions default on; disable `compatibility.enable_augment_extensions` in `ars_conflux-startup.toml` on both sides and restart to restore upstream behavior. All three upstream mods remain optional.
