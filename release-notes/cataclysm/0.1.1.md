# Cataclysm & Nouveau 0.1.1

- Add Minecraft 1.20.1 Forge support, with the same 102 glyphs and shared version as the NeoForge edition.
- Adapt native projectile movement, collision and visual ticks, tentacle capabilities, explosion damage handling, status effects and phantom packets to the Forge release.
- Preserve successful native-hit continuation, resource handling and owner cleanup, including repeating Ars projectile forms.
- Fix blank native 3D item glyph icons on both platforms while preserving Ars glyph frames and native GUI transforms.
- Fix the missing Abyss Mark glyph texture by adding a runtime atlas reference. No Cataclysm artwork or implementation code is bundled.

Forge requires Ars Nouveau 4.12.7, Cataclysm 3.31, Lionfish API 3.0 and their normal dependencies. NeoForge remains available for Minecraft 1.21.1. Use Ars Conflux 0.1.30 for the corrected GUI frame brightness.

Both platforms passed real client glyph previews. Focused Forge server regression checks passed; not every Boss animation and optional addon combination has been manually tested.
