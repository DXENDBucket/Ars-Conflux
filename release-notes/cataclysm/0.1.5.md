# Cataclysm & Nouveau 0.1.5

**Requires Ars Conflux 0.1.47 or newer within 0.1.x.**

Minecraft **1.21.1 NeoForge** and **1.20.1 Forge**.

- Fix real-executor direction and pitch reads in body-action steering, death-laser tracking, guardian actions and directional fallbacks. Internal animation proxy transforms are retained.
- Keep explicit position/direction execution, native targeting and bounded steering rules unchanged.
- Include optional AI ability hints for all 102 glyphs from 0.1.4, with usefulness checks for existing buffs and capped rage. This does not automatically install mob AI.

Validation: both platform distributions compile and package successfully; metadata and declared Forge refmaps were checked. This batch has not been checked in a running client or server.
