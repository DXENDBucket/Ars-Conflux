# BOMD & Nouveau 0.1.1

Requires Ars Conflux 0.1.32.

Gauntlet Laser now supports Extend Time / Duration Down. Each unit changes actual active output by one second, with the existing three-second base and bounded duration. Charge-up and aim lag are unchanged. Additional active seconds still pay their normal resource fee, and depleted/expired beams close their client visual leases.

Laser phase timing now follows elapsed world ticks, preventing an extra active-second charge at a same-tick startup boundary.
