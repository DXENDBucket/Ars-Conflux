# Ars Fusion 0.2.1

For Minecraft **1.21.1 NeoForge** and **1.20.1 Forge**.

- Fix the reported ammunition-predicate redirect conflict with **Vampirism**.
- Fused bows and crossbows now compose the stored native predicate result rather than redirecting the same getter calls. Other mods retain their own supported ammunition, while Fusion can still add Ars augment arrows.
- Preserve native held-ammo priority, inventory ordering and the exact weapon being queried. Ordinary unfused equipment is unchanged.
- No Vampirism-specific dependency or Mixin priority override is added.

Both platform packages and regression test sources compile. Native bytecode and Forge production mappings were checked; an actual Vampirism coexistence game session has not been run for this fix.
