# Ars Fusion 0.1.7

Available for Minecraft **1.21.1 NeoForge** and **1.20.1 Forge**.

- Add **reverse armor fusion**: place other armor on the left and same-slot Ars armor on the right in a normal anvil, consuming both items and one XP level.
- Keep the receiving armor's identity, appearance, durability, enchantments, attributes and native abilities. Transfer the Ars armor's thread slots, current upgrade tier, installed threads and saved thread state.
- Continue using the native Ars alteration table to remove or install threads, and native armor upgrade recipes to upgrade the thread layer without replacing the original armor.
- Apply native thread attributes, event effects and equipped-player tick effects. Ars armor's own base Mana, base regeneration and optional base tier-toughness bonus are not copied.
- Add `armor_fusion.reverse_enabled`, enabled by default under the existing armor-fusion master switch. Disabling new fusion preserves existing results.
- Reject wrong-slot inputs, armor with an existing Ars thread layer and repeated or nested armor fusion. Unfused stacks of the same armor item do not gain thread slots.

Both platforms compile and package successfully, including the new regression test sources. Forge production reobfuscation and refmap checks passed. This release was not tested by launching a client, server or GameTest; client visuals and in-game behavior remain unverified.
