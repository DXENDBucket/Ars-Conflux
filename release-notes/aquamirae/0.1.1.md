# Aquamirae & Nouveau 0.1.1

Requires Ars Conflux 0.1.32.

Add matching Dampen / Duration Down support for status, sting, bite and aura abilities, including native lower bounds. Signed values now affect the intended intensity, damage, duration or vortex health limit. Positive baselines and native resource/alliance rules are retained; higher-tier positive amplification equivalents use weighted units for the existing surcharge.
