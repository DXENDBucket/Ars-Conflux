# Ars Instinct 0.1.5

Initial CurseForge release for Minecraft 1.21.1 / NeoForge and 1.20.1 / Forge.

A developer-focused library for reusable Ars spellcasting AI. Installing it alone does not give ordinary mobs spells, equipment or combat targets.

- Provide a caller-owned combat controller, an explicitly installed ground combat Goal, and a backend API for tool/program/resource integration.
- Use starting cast forms and Conflux ability hints to select supported attacks, healing and buffs for enemies, self or allies.
- Plan using real resource budgets and native cooldown facts, including waiting for affordable spells and fairer opportunities for programs sharing cooldowns.
- Support native Self, Touch, registered projectile forms and supported rays; optional NEG ray integration needs no hard NEG dependency.
- Resolve Touch through native entity/block interaction paths with actual clipped hit geometry.
- Add opt-in, bounded and cached projectile-awareness snapshots. Content code decides how to react; no global dodging or projectile changes are installed.
- Offer default-off server configuration for selected entity IDs or tags, with optional mana overrides.

Requires Ars Nouveau and Ars Conflux 0.1.45+ within 0.1.x. Iron and Goety are not required. MIT, EndXiom.
