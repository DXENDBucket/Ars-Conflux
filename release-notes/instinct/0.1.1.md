# Ars Instinct 0.1.1 — Initial release

Reusable, opt-in spellcasting AI for Ars Nouveau programs. Available for Minecraft **1.21.1 NeoForge** and **1.20.1 Forge**; requires Ars Nouveau and **Ars Conflux 0.1.45+**.

- Read actual equipped Ars tools and choose among their saved programs using ability hints, recipients, range, native resource budgets and provider cooldowns.
- Use the real creature as caster and the native Ars mana pool. Support attacking, useful self/ally abilities and saving mana for a selected program.
- Offer an explicit installation API and a **default-off** server option for selected entity IDs or the `ars_instinct:spellcasters` entity-type tag.
- Retain the creature's native target selection. No automatic equipment, generated spell groups, universal hostility or natural-spawn changes.
- Keep complex/unlabelled programs conservative; ground navigation has a supplied goal, while content mods can retain custom flight and use the controller directly.

Iron, Goety and specific modpacks are not required. Soul-based abilities still need an actual usable resource account. Targeted standalone server checks passed on both versions, with additional mixed-mod checks. Client visuals were not manually verified.
