# Iron & Nouveau 0.17.43

For Minecraft **1.21.1 NeoForge** and **1.20.1 Forge**.

## Boss and item abilities

- Add six glyphs without native scroll equivalents: **Undead Rift**, **Fiery Dagger**, **Dagger Zone**, **Ring of Fire**, **Expulsion** and **Ominous Fire Orb**.
- Use native Iron entities, effects, sounds and lifecycle behavior, with real Scribe recipes and Conflux/Instinct ability hints. Original boss behavior is unchanged.
- Ominous Fire Orb places a destructible timed orb, retaining its charge, countdown, fiery explosion and Immolate effects. Its final base trigger cost is **400 Mana**, reduced from 600 to account for the long detonation delay.
- Add ability hints for all 109 dedicated glyph adapters. This does not automatically give mobs casting AI.

## Fixes

- Fix English and Simplified Chinese names for the six new glyphs using Ars's actual namespaced language keys.
- Add packaging-time name-key validation.

New ability adapters received targeted server testing during development. The final cost-only adjustment was verified in both release binaries without rerunning the game. Both loaders, resources and Forge production mappings were checked; client visuals were not manually retested.
