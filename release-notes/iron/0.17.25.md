# Iron & Nouveau 0.17.25

## Optional armor fusion

- Add a vanilla-anvil fusion: place Ars armor on the left and Iron armor for the same equipment slot on the right. Fusion consumes both inputs and one experience level; each Ars piece can be fused only once.
- Keep the Ars item, appearance, durability, enchantments, dye, threads and native armor upgrades. Add the Iron donor's attribute bonuses except armor and armor toughness.
- Transfer the donor's native Iron spell container, including an already imbued spell. Compatible fused armor can still be imbued through Iron's native Arcane Anvil.
- Preserve fusion data and imbued spells through native Ars upgrades, saving and synchronization. Custom anvil names remain supported.

This feature is **disabled by default**. Enable it in `irons_nouveau-server.toml`:

```toml
[armor_fusion]
enabled = true
```

## Optional Ars armor toughness

- Add an independent `armor_fusion.ars_toughness_per_tier` setting, defaulting to `0.0`.
- Set it to `1.0` to grant each Ars armor piece an extra 1 / 2 / 3 toughness at displayed armor tier 1 / 2 / 3. This also works on unfused armor and follows native armor upgrades.

Existing equipment is unchanged with the default settings. Disabling new fusion crafting does not strip previously fused equipment.

Available for Minecraft 1.21.1 / NeoForge and Minecraft 1.20.1 / Forge.
