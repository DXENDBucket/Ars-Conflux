# Iron & Nouveau 0.17.45

## Wind's Spellbooks integration

All seven spells now have dedicated Ars integration instead of the generic self-cast fallback:

- **Wind Blade:** projectile replacement, retaining its native blade, growth, piercing and damage behavior.
- **Tornado / Almighty Push:** effects that can trigger at a selected entity or location.
- **Tailwind / Wind Jump / Iron Slash / Aeropic:** effects executed by the caster or a selected ally, with native status, movement and visual behavior.

Supported spells use the existing level, resource, casting-time and cooldown settings. Appropriate augments affect level, area or duration, and projectile carriers use the shared Conflux trajectory support. Scribing recipes accept a corresponding scroll and a source gem. Wind's Spellbooks remains optional.

Existing glyph IDs are preserved. **Wind Blade is now a projectile replacement**: old Self → Wind Blade recipes must be rewritten to use a projectile carrier. Aeropic performs one native dash per Ars trigger; the native spell book's additional recast interaction is not an extra Ars casting stage.

Added matching glyph descriptions, native spell icons and Ars Instinct ability hints. Invalid recipients do not silently redirect an allied spell back to the caster.

Available for Minecraft **1.21.1 NeoForge** and **1.20.1 Forge**, targeting Wind's Spellbooks **1.0.5 / 1.0.3** respectively. Dedicated native-behavior, optional-dependency and projectile-carrier tests passed; complete client visual parity has not been manually verified.
