# Iron & Nouveau 0.17.24

- Add a first-login chat notice when Ars 'n Spells is also installed. Its 3.4.0+ Iron spell glyphs overlap with some features of Iron & Nouveau; older Ars 'n Spells versions can ignore the notice.
- Explain how a server administrator can keep using Iron & Nouveau's glyphs by setting `enable_iron_glyphs = false` and `enable_glyph_press = false` in the `Imported Iron's Glyphs` section of `<world>/serverconfig/ars_n_spells-server.toml`, while retaining Ars 'n Spells' mana and attribute integration.
- Show the notice once per player per world, with English and Simplified Chinese translations. The read flag persists across reconnects and death. No other mod's configuration is changed automatically, and Ars 'n Spells remains optional.

No changes to spell damage, costs, cooldowns, glyph learning or projectile behavior.

Available for Minecraft 1.21.1 / NeoForge and Minecraft 1.20.1 / Forge.
