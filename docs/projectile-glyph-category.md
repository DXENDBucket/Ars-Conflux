# 弹射物替换分类

Conflux 0.1.52；NeoForge 1.21.1 / Forge 1.20.1。

法术书将实现 `ProjectileForm` 的魔符单独归入「弹射物替换」，排在普通形态之后、普通增强之前。同一魔符不会同时占据增强分类。既有提供者排序与其他附属的分类保留；NeoForge 的 Zero 魔杖目录使用相同分类。

这是展示分类，不改变 `AbstractAugment` 继承、原有类型索引、配方解析、施法校验或存档 ID。附属已经实现 `ProjectileForm` 的替换魔符自动接入，无需逐个更新。没有实现该接口的第三方魔符不会仅凭名称被猜测为替换魔符。

## 图标

替换魔符使用 Ars 原有底板与增强外框，外围改为深黑色，中心仍使用附属声明的图标或物品模型。NeoForge 分类图标复用 Ars 增强分类的构图，仅重染背景，保留浅色符号。Forge 的 Ars 4 界面使用原生文字标题布局。

```toml
# config/ars_conflux-client.toml
[glyph_icons]
projectile_color = "#202020"
```

该颜色同时用于替换边框与分类图标，在默认 `ARS_TYPE` 模式也生效。`UNIFORM` 模式继续遵循统一颜色。已有外框开关仍有效；本次没有把上游图片复制进发行包，纹理取自当前资源包并在重载时更新。

## 法术轮盘

轮盘主图标优先显示第一段实际效果所用的替换载荷，例如：

| 编排 | 主图标 |
| --- | --- |
| 弹射物 → 火球 | 火球 |
| 自身 → 环绕之球 → 闪电球 | 闪电球 |
| 弹射物 → 伤害 | 原版伤害 |
| 自身 → 治疗 → 后续弹射物载荷 | 治疗 |

隐含形态的工具模板也能识别开头的替换载荷。原有形态小图标、槽位名称与切换行为保留，不会因后段载荷而覆盖前段已有效果的图标。

## 验证

- 定向单元测试覆盖预览选择、外框颜色、分类排序与两版分页模型。
- NeoForge 隔离客户端同时加载 Iron & Nouveau、NEG、Elemental、Zero，实际绘制分类网格、背包图标，并断言原生轮盘构建结果及分类排他性。
- 两平台发行包构建；Forge 执行重映射及发行包检查。
- Forge 本批未启动客户端；NeoForge 未逐页人工遍历完整整合包所有魔符。
