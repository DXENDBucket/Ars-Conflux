# 通用吟唱／冷却缩减（0.1.40）

Conflux 注册两种同步的生物属性，两平台 ID 相同：

| 属性 | 默认值 | 含义 |
|---|---|---|
| `ars_conflux:cooldown_reduction` | 0 | 对提供者算完原生规则后的冷却再缩减 |
| `ars_conflux:cast_time_reduction` | 0 | 对统一准备时间再缩减 |

值为比例：`0.25` 表示额外缩短 25%，`1` 表示缩短 100%。同一属性的装备修饰先由 Minecraft 属性系统合并，再应用一次 `原时间 × (1 − 属性值)`。范围为 −10 至 1；负值可延长时间。没有额外软上限；原模组自己的软上限继续在前一阶段生效。

正的不足一 tick 的时间向上取整；100% 可归零。默认 0 时原有行为不变。属性附加到所有已具有默认属性的生物类型，玩家与怪物均可使用；缺少该属性的自定义实体按 0 处理。

## 应用范围

- 主动施法：`ActiveCasts` 先完成各提供者原生准备时间以及 MAXIMUM／SUM 汇总，再调用 `CastingTiming.chantTicks` 一次。Hex Linker、Zero 等已接入的主动入口共享同一规则。
- 自定义冷却：`PersistentCooldowns.Namespace.extend` 和 `commit` 在记录新冷却时应用缩减。因此现有灾变、BOMD、海灵、Mowzie、传奇怪物提供者无需为此逐一发布新版本。
- Iron & Nouveau 0.17.31：在原生 CDR、武器倍率与单发重施分摊之后应用通用缩减；包括接入的原生自身施法及非玩家绑定工具冷却。保留原生事件、存储与同步。未经过联动的 Iron 原生施法不额外改变。
- Goety & Nouveau 0.1.5：在原生冷却计算之后应用通用缩减。原生自身聚晶的准备、棱镜光束的目标依赖准备也会缩短；本体或附属聚晶在原生自身作用域内直接写入的冷却同样处理。未经过联动的 Goety 原生施法不额外改变。

不修改 Ars“延迟”、持续吐息／光束的有效输出时长、脉冲间隔、弹射物速度、动作动画及其命中帧。不新增原来没有的冷却或吟唱。原有创造模式、入口配置、失败与取消规则继续适用。原生实体技能可能仍至少占用一个 tick 来完成生命周期；零吟唱不等于零执行时长。

缩减在新准备开始／新冷却写入时取一次快照，中途换装不改写已开始的计时。冷却记录仍采用“延长至较晚截止时间”，较短的新来源不缩短已有冷却。`commit` 在提交前冻结最终时间，延后确认成功时不再缩减第二次。

## 使用

仅注册属性，不附送装备或永久加成，也不自动把 Iron／Goety 的原生属性复制到这里。整合包可通过物品属性修饰、饰品、奖励等赋予。开发调试可使用：

```mcfunction
/attribute @s ars_conflux:cooldown_reduction base set 0.25
/attribute @s ars_conflux:cast_time_reduction base set 0.25
```

恢复默认：把两项 `base set` 设回 `0`。上述命令修改的是属性基础值；若测试装备加成，应使用独立修饰符而非重复覆盖基础值。

## 提供者 API

`CastingTiming.chantTicks(caster, nativeTicks)`／`cooldownTicks(caster, nativeTicks)` 接受已完成原模组修饰的时间。吟唱提供者的 `chantTicks` 返回原生计算结果即可，由 `ActiveCasts` 统一缩减，不要预先调用帮助方法。

使用公共冷却存储时，`Namespace.extend`／`commit` 接受提供者有效原生时间，不要再预缩减。`extendRaw` 是显式写入最终时间的底层操作，供恢复或已完成计算的调用者使用。旧的零属性调用保持兼容；若其他附属原先预先使用了新的缩减 API，应改为 `extendRaw`，避免重复处理。

原生系统自行存储冷却的提供者，在写入边界调用一次 `CastingTiming.cooldownTicks`。持续技能中原生回调接收到的“已准备时间”仍应映射到完整的原生进度，不能因缩短等待而让原生代码认为尚未蓄力完成。

这两个属性不意味着能无条件改变任意 Ars 附属的私有计时；未接入 Conflux 的私有冷却仍由其作者负责适配。

## 验证

定向用例覆盖无 Iron／Goety 的独立注册、默认中立、原生值后乘、截止时间快照、成功后提交不重复缩减、已有冷却不重算、MAX／SUM 共用准备、100%／负值／溢出及纯 Ars 不新增吟唱。Iron 与 Goety 分别补充原生冷却接入及原始施法不受影响的用例。
