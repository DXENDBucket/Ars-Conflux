# 执行者视角核对（2026-10-31）

用户报告的是 Ars 编排让友军执行定向 Goety 聚晶时喷吐/冲刺方向不对。实体的 getLookAngle() 读取身体 yaw，而 getViewVector(1) 通过 LivingEntity.getViewYRot(1) 读取头部 yaw；玩家通常一致，怪物可以不一致。这是适配层的方向语义缺口，不是需要替实体增加姿态同步。此前的狱焰同步方案已撤销。

Core 0.1.47 新增 ExecutionAnchor.viewDirection(Entity)，统一有限、归一化的当前视角向量；实体锚点采样、缺少入射方向时的回退及受控弹体的持有朝向使用头部视角。位置锚点与明确入射方向保持原有优先级。

| 项目 | 核对与修正 |
| --- | --- |
| Conflux | 实体执行锚点、落点方向回退、受控弹体持有方向 |
| Goety | 吐息粒子/命中/引燃方向、原生方块射线、水平偏移、腐化光束、发射推动、自身冲刺、方向回退、水鞭原生主人朝向 |
| Iron | 实体吐息/射线、客户端吐息跟随与口部偏移、燃烧冲刺/伏特打击/暗影斩击/升腾、念力瞄准、自身步进前方查询 |
| BOMD | 巨拳激光持续跟随与方向性地面效果/传送执行者 |
| Cataclysm | 实体动作方向与俯仰、追踪回退、死亡激光、守卫动作和原施法者方向回退；动作代理模型内部旋转保持不动 |
| Aquamirae | 鳗鱼咆哮的前向筛选和粒子起点 |
| Mowzie | 地卜方向回退、太阳光束的非玩家口部偏移；光束原生 yaw 已读取 yHeadRot |
| Legendary | 持续能量/湮灭光束、火焰吐息的执行锚点与方向回退 |
| Instinct / Fusion | 扫描未发现另一个直接读取 getLookAngle 的定向执行实现；Instinct 瞄准同时设置头/身，但不能用这点替代正确的执行方向语义 |

不是全局替换 getYRot/getLookAngle：原生弹体/锥体自身姿态、人工动作代理坐标系、玩家骑乘操纵、传送目标背后候选位置、附着手臂的身体偏移等仍保留各自语义。没有把选中目标自动当付款人或伤害来源。Goety 冲刺原有“目标/落点让施法者冲向那里，自身触发沿朝向”的规则不改；此批修正其自身视角和回退方向，发射推动则直接读取实际受益友军视角。

构建和原生调用点核对不能证明客户端画面已通过。按用户限制，本批不运行 GameTest/客户端/服务端，不替换共享实例。后续应对比头身相差约90度的生物，转动头部时观察吐息、冲刺、光束两端及方块/实体命中；另检查位置执行和常规原生施法没有被改变。构建结果/产物哈希由同批记录提供。
