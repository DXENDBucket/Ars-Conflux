# 原生弹体续接交接（2026-10-13）

Core 0.1.24，运行 API 提交 `08c307f3238b9b9aa7fd628b9771cd287160448d`。工作分支 `fix/projectile-impact`；五个附属使用各自固定该提交的 Core 副本，受版本控制文件未变化。

## 已确认的行为

- 直接伤害弹体命中实体：本次完整原生碰撞内，该目标的 hurt 接受成功才续接；不比较 HP，不让爆炸伤到其他目标代替命中目标的成功。
- 方块命中：碰撞续接，保留命中地形后的组合能力。
- 区域、纯状态、照明及非即时伤害长枪：用户确认在原生区域或状态成功建立时续接，不等待后续 tick 伤害。提供者负责具体资格与激活，Core 不认识原模组能力。
- 原生碰撞全部执行，特效、爆炸、子实体、原生状态及生命周期保留；观察关闭后才执行后续编排。作用域嵌套及异常正确恢复，重入 hurt 监听器不能批准被拒绝的外层伤害。
- 不更改既有收费政策：已执行的原生尝试仍按提供者现有政策计费，后续没执行的魔符不新增费用。海灵飞轮仍按 accepted hurt 收费，方块续接成为有效付费触发。
- Iron 的直接伤害成功钩子与纯状态成功钩子已符合约定，源码和 0.17.20 包保留。没有改纯 Ars 的普通命中规则，也没有添加频率限制或独立性能保护。

具体入口和 API 见 [约定](projectile-impact-triggers.md) 与各附属 `docs/projectile-impact-triggers.md`。
